# Ayame TV 0.2.1

- Give the Settings category rail one continuous glass surface so wallpaper
  details do not sit directly behind unselected navigation labels.
- Use the shared frost and contrast protection for the Settings content surface
  instead of a fixed translucent overlay.
- Keep Settings as a full page, with independent scrolling and remote navigation.
- Add emulator boot-only options and the official-baseline installation helper;
  fix the release watcher to follow tag-triggered builds too.

This is version code 4 and updates official 0.1.0 or 0.2.0 installations in place
using the existing release signing key.

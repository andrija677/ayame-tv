# Architecture

`MainActivity.kt` owns lifecycle, activity results, package-change observation,
background work, persistence, and launching Android activities.

`LauncherData.kt` contains the theme/preferences schema, launcher discovery,
bounded image import, palette extraction, and theme import/export. Apps are
discovered through declared launcher-intent queries. No broad package permission
is requested. TV activities take priority over phone ones. Network and package
installation permissions support only the user-initiated release updater.

`UpdateManifest.kt` validates versioned release metadata and download hosts;
`ReleaseUpdater.kt` handles bounded HTTPS, integrity checks, and archive signature
validation. `MainActivity` owns update UI state and Android's permission/installer
handoff. `version.properties` is the shared build/release version source. See
`RELEASING.md` for signing and publication.

`LauncherUi.kt` contains the Compose home, app grid, focusable controls, theme
tokens, app options, and settings. Popup/dialog focus roots isolate modal panels.
Focus requests restore navigation after dismissal. Stable component IDs key app
lists and favorites. Animation durations become zero when motion is disabled.

The default background is generated by Compose gradients; there is no bundled
third-party wallpaper. User wallpaper processing happens off the main thread,
is bounded to 40 MB encoded input, and downsamples to at most 2560 × 1440.
Theme input is limited to 64 KB and settings are clamped to supported ranges.

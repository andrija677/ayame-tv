# Architecture

`MainActivity.kt` owns lifecycle, activity results, package-change observation,
background work, persistence, and launching Android activities.

`DeviceControls.kt` reads local network capabilities and media-volume state and
defines public device-settings routes. Quick Settings polls that local snapshot
every 1.5 seconds only while its popup is open and the activity is STARTED. The
activity pauses observation under system settings and cancels it on dismissal.
Device controls use normal network-state/audio-settings permissions; no SSID,
location, Bluetooth enumeration, radio toggles, or external status requests are used.
Fixed-volume devices receive sound-settings access without volume step buttons.

`LauncherData.kt` contains the theme/preferences schema, launcher discovery,
bounded image import, palette extraction, and theme import/export. Apps are
discovered through declared launcher-intent queries. No broad package permission
is requested. TV activities take priority over phone ones. Network and package
installation permissions support only the user-initiated release updater.

`UpdateManifest.kt` validates versioned release metadata and download hosts;
`ReleaseUpdater.kt` handles bounded HTTPS, integrity checks, and archive signature
validation. `MainActivity` owns update UI state and Android's permission/installer
handoff. `version.properties` is the shared build/release version source. See
`RELEASING.md` for signing and publication.

`LauncherUi.kt` contains the Compose home, app grid, focusable controls, theme
tokens, app options, and full-page settings. Home content is removed while the
settings page is displayed; app options and the gallery remain modal. Focus
requests restore navigation after returning. Stable component IDs key app
lists and favorites. Animation durations become zero when motion is disabled.

`StylePresets.kt` defines validated navigation, tile, and clock choices plus
four visual presets. Applying a preset copies appearance fields without changing
the user's palette, artwork, favorites, app visibility, or animation preferences.
Old JSON themes receive the original styles as defaults; unknown choices fall back.

`FrostedWallpaper.kt` makes a shared texture capped at 384 pixels on its longest
edge, using separable box passes on a worker dispatcher. Glass surfaces sample
that texture without individual GPU blur effects. The original wallpaper is kept
for the full-screen background; no artwork is processed during focus animation.

The initial background is generated by Compose gradients. Twelve test wallpapers
are bundled in `assets/wallpapers` with source attribution. Opening the gallery
extracts the pack into a versioned cache directory on the IO dispatcher; cache
eviction simply regenerates it on next use. Increment the cache directory version
and `SOURCES.json` packVersion when changing existing pack images. Thumbnail
sizes remain bounded and duplicate filenames from local samples are removed.
User wallpaper processing happens off the main thread,
is bounded to 40 MB encoded input, and downsamples to at most 2560 × 1440.
Theme input is limited to 64 KB and settings are clamped to supported ranges.

2. Test navigation, long-press behavior, dialogs, file picker availability, and
   background/foreground transitions on the Xiaomi Stick.
